# portal-komponenter

Felleskomponenter for eksterne portaler i Lånekassen.

- [Inaktivitet](packages/inaktivitet/README.md): varsling om utløpende sesjoner.
- [Samtykke](packages/samtykke/README.md): samtykkebanner for informasjonskapsler.
- [Riktekst](packages/riktekst/README.md): rendring av strukturert riktekst.
